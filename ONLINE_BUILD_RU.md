# Онлайн-сборка и проверка End Update

## Рекомендуемый вариант: GitHub Actions

В проект уже добавлен `.github/workflows/build.yml`.

После загрузки проекта в GitHub workflow автоматически:

1. поднимает Ubuntu;
2. ставит Temurin Java 17;
3. ставит Gradle 8.1.1;
4. выполняет `gradle --no-daemon clean build`;
5. сохраняет готовый `build/libs/*.jar` как Artifact `endupdate-forge-1.20.1`.

Это полноценная ForgeGradle-сборка, а не обычная проверка Java-кода.

### Как запустить

1. Создать пустой репозиторий GitHub.
2. Загрузить в корень всё содержимое этого проекта, включая папку `.github`.
3. Открыть вкладку **Actions**.
4. Выбрать **Build End Update**.
5. Нажать **Run workflow**.
6. После успешного завершения скачать Artifact `endupdate-forge-1.20.1`.

При push в `main`/`master` и при Pull Request обычная сборка запускается автоматически.

## Проверка запуска dedicated server

Второй workflow: `.github/workflows/server-smoke-test.yml`.

Он запускается вручную и делает более дорогую проверку:

1. сначала компилирует мод;
2. создаёт тестовый `eula.txt`;
3. запускает Forge `runServer`;
4. ждёт, пока сервер дойдёт до состояния `Done (...)!`;
5. падает с ошибкой, если процесс завершился раньше или не загрузился за 180 секунд;
6. сохраняет серверный лог как Artifact даже при ошибке.

Это ловит много ошибок регистрации, common/server кода, datapack/worldgen JSON и загрузки мода. Оно **не заменяет запуск клиента**: текстуры, рендер сущностей и визуальные артефакты нужно проверять в клиенте.

## GitHub Codespaces

Codespaces подходит, если нужен браузерный VS Code: можно открыть репозиторий в Codespace, поставить/использовать Java 17 и запускать Gradle из терминала. Для повторяемой автоматической проверки Actions лучше, потому что каждый build идёт в чистом окружении.

## Почему обычные online Java compiler сайты не подходят

Forge 1.20.1 — не один `.java` файл. Нужны ForgeGradle, Minecraft/Forge зависимости, Mojang mappings, ресурсы, reobfuscation и несколько гигабайт памяти. Сайты уровня «вставил Java-код — Run» этого не воспроизводят и могут дать ложное ощущение, что мод проверен.
