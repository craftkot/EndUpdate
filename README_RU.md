# End Update — Forge 1.20.1

Текущий прототип мода, развивающий ванильный End без замены самого хоруса новым деревом.

## Что уже реализовано

### Хорусовая «древесина»
- Ванильное растение хоруса не изменяется.
- 4 `minecraft:chorus_fruit` (2x2) -> `endupdate:chorus_stem`.
- 1 стебель -> 2 хорусовые доски.
- Доски, мозаика, ступени, плиты, мозаичные ступени/плиты, забор, калитка, дверь, люк, нажимная плита и кнопка.
- Хорусовые доски добавлены в ванильный тег `minecraft:planks`, поэтому работают в обычных рецептах, использующих доски.

### Каменные инструменты из эндерняка
`minecraft:end_stone` добавлен в `minecraft:stone_tool_materials`. Поэтому стандартные ванильные рецепты каменного меча, кирки, топора, лопаты и моты принимают эндерняк без дублирования рецептов.

### Эндер-мобы
- End Zombie: после получения удара от сущности телепортируется как хорус (с коротким cooldown).
- End Skeleton: стреляет особыми стрелами, телепортирующими выжившую цель после попадания.
- End Creeper: во время подрыва может телепортироваться ближе к далёкой цели.
- End Spider: периодически делает короткий телепортационный рывок к далёкой цели.
- Все 4 варианта имеют отдельные spawn eggs, End-текстуры и loot tables.
- Естественный спавн добавлен во внешние биомы Энда через Forge biome modifiers.

### Телепортационное зелье
- База специально необычная: `Thick Potion` + хорус -> Potion of Teleportation.
- Есть обычная, splash и lingering формы.
- Эффект мгновенный: случайная безопасная телепортация примерно в радиусе хоруса.
- Lingering-вариант позволяет получить ванильную tipped Arrow of Teleportation.

### End Trial Dungeon
Это не копия Trial Chambers. Данж генерируется отдельным алгоритмом из End Stone Bricks, Purpur, Obsidian и End Rods:
- центральная арена;
- четыре пилона;
- четыре боковых сектора;
- центральное неразрушаемое Trial Core;
- 3 волны End-мобов;
- trial-мобы получают ID конкретного ядра, поэтому естественные мобы не мешают прохождению;
- телепортировавшиеся за пределы арены trial-мобы возвращаются внутрь;
- после победы активируется сундук с эндовым лутом;
- повторное испытание после 10 минут перезарядки.

## Важно: сборка
Проект рассчитан на Minecraft 1.20.1 + Forge 47.4.10 + Java 17.

В среде, где проект создавался, нет Gradle/Forge-кэша, а загрузка Forge MDK с `maven.minecraftforge.net` недоступна, поэтому фактический `gradlew build` здесь пока не выполнен. Исходники и ресурсы подготовлены, но до первого реального запуска нельзя честно гарантировать отсутствие компиляционной/API-ошибки.

Для локальной сборки проще всего взять официальный Forge 1.20.1-47.4.10 MDK, сохранить из него `gradlew`, `gradlew.bat` и `gradle/wrapper`, затем наложить на него файлы этого проекта и выполнить на Java 17:

```text
./gradlew build
```

Windows:

```text
gradlew.bat build
```

Готовый jar после успешной сборки будет в `build/libs/`.
