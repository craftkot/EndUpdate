# Changelog

## 0.2.0
- Данж расширен с декоративных ниш до четырёх полноценных боковых боевых комнат и коридоров.
- Добавлена проверка рельефа и более глубокие опоры пола.
- Trial Core охватывает весь данж, а не только центральную арену.
- Добавлено масштабирование волн для группы игроков.
- Брошенное испытание сбрасывается через 30 секунд и очищает своих мобов.
- Idle Trial Core опрашивает игроков раз в 10 тиков вместо тяжёлого сканирования мобов каждый тик.
- Добавлены звуки/portal particles для старта, волн и победы.
- End Creeper теперь делает направленный chorus-blink в область цели.
- Естественные End-варианты мобов получили более умеренные веса спавна, чтобы не вытеснять эндерменов.
- Зелье телепортации варится только как обычное из Thick Potion + Chorus Fruit; splash/lingering/tipped arrow идут по ванильной цепочке.
- Door/Trapdoor модели переведены в cutout render type.
- Хорусовые рецепты открываются в книге рецептов после получения Chorus Fruit.
- Добавлен dependency-free `tools/static_audit.py`.
- Добавлены GitHub Actions для Forge build и dedicated-server smoke test.
- Версия проекта поднята до 0.2.0, jar настроен на `reobfJar`.

## 0.1.0
- Первый полный исходный прототип: хорусовые блоки, End Stone tools, 4 End-моба, teleport potion/arrow, Trial Core и первичная генерация данжа.
